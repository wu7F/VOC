VOC

飞书数据源配置指引

VOC 洞察平台 · 售后 VOC · 让看板随飞书表格自动更新（服务器端运行，不依赖任何人的电脑开机）

为什么要配这个？
平台要直接从飞书读取售后表格，需要一个「飞书自建应用」作为身份凭证。 配好之后，平台服务器会按你设的间隔自动去拉表格、重新分析、刷新看板 —— 你的电脑关机、公司网络断开都不影响。
全程约 5 分钟，只需要做一次。

配置步骤

  1. 创建企业自建应用
    打开开发者后台 → 点「创建企业自建应用」→ 随便起个名字（比如 VOC 洞察平台），选好企业后创建。
    → https://open.feishu.cn/app
  2. 申请读取表格的权限
    在应用后台左侧「权限管理」→ 搜索并开通下面这些权限 （建议全选，这样电子表格 / 知识库里的表格 / 云空间文件都能接）：
    权限标识用途
    sheets:spreadsheet:readonly读「电子表格」
    bitable:app:readonly读「多维表格 Base」
    wiki:wiki:readonly读「知识库里的表格」
    链接形如 /wiki/xxx 时必需
    drive:drive:readonly
    drive:file:download    		读「云空间里上传的文件」
    链接形如 /file/xxx 时必需
    注意：权限申请完还必须走下一步「发布版本」才会生效，只申请不发布是没用的。
  3. 发布版本
    左侧「版本管理与发布」→ 创建版本 → 填个版本号（如 1.0.0）→ 发布。 部分企业需要管理员审核，审核通过后权限即生效。
  4. 把目标表格授权给应用
    打开你要接入的飞书表格 → 右上角「分享」→ 「添加协作者」→ 搜索你刚创建的应用名称 → 添加为**可编辑**协作者。
    应用必须被单独授权，仅「在文档里提到它」或同在一个空间是不够的。
    表格在知识库里（链接是 /wiki/xxx）？
    同样要在这张表格的「分享」里把应用加为协作者，另外还要有 wiki:wiki:readonly 权限，否则平台解析不出背后的真实表格。
  5. 拿到 app_id / app_secret
    左侧「凭证与基础信息」→ 就能看到 App ID（形如 cli_xxxxxxxx）和 App Secret。
    App Secret 是敏感信息，不要发到聊天群里、不要贴进代码仓库。
  6. 填进平台并保存
    回到平台 → 售后 VOC → Amazon售后 标签 → 「飞书数据源」卡片 → 展开「飞书应用凭证」→ 填入 app_id / app_secret → 点「保存」。
    然后在同一个卡片里：
    • 「粘贴飞书表格链接」→ 填你的电子表格链接
    • 「数据源名称」→ 如「亚马逊店铺1 · GN品牌售后登记」
    • 「自动同步间隔」→ 分钟数，建议 30（半小时一次）
    • 点「保存数据源并立即同步」
    验证成功的样子：数据源列表出现该条目、状态为 ok， 上方显示「刚刚同步」，消息是「完成 · N 条售后登记 · 台账模式…」； 点顶部「售后VOC」直接进看板，数据已是最新。

常见问题

报「尚未配置飞书应用凭证」

凭证没填或没保存成功。展开「飞书应用凭证」填 app_id + app_secret，点「保存」。

报 99991663 / permission denied

应用没有该表格的权限。回第 4 步，在表格「分享」里把应用加为协作者。

报 permission denied（权限维度）

权限没申请或没发版生效。回第 2、3 步，开通权限并发布版本。

表格读出来是空的

检查表格里第一行是不是真表头（说明行/空行会被自动跳过），以及「产品」列能否被识别。

另：服务器也可以用环境变量 VOC_FEISHU_APP_ID / VOC_FEISHU_APP_SECRET 配置， 这样多人使用同一套凭证、且不必在网页上重复填写。
